# World Map Sources

- `world-countries.geojson`: Natural Earth, 1:110m admin-0 countries, public domain. Downloaded from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . Boundaries are cartographic reference data, not economic observations.
- `../js/d3.min.js`: D3 7.9.0, ISC license, https://github.com/d3/d3 . Used for the Natural Earth projection and geographic paths.
- Rates are loaded from FMP's Economic Data Releases Calendar using the app's configured connection. No economic values are bundled with the map.
